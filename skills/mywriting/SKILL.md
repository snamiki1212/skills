# 日本語の文章規範（構成・論証・推敲）

日本語の文章を書く・推敲するときは、この規範に従う。
この SKILL.md は読み分けの管理だけを持つ。規範の本体は `references/` にあり、責務ごとにファイルを分けている。

- **references/formatting.md**：整形。一文一行、記号と太字の使い分け、箇条書き・テーブル・見出しの記法といった表記の機械的ルール
- **references/composition.md**：内容の規範。段落と論証の構成、論証の厳密さ、読み手の負荷の管理、視点と語り、見出しの付け方、読者への誠実さ
- **references/deslop.md**：推敲。演出の抑制、LLM っぽい表現の禁止、冗長の排除
- **references/structure.md**：複数ファイル構成。ファイルの単一責任、参照の書き方、ファイル構造の SLAP

`references/` の各ファイルは責務で分けた同列の単位である。この skill の文書それ自体にも、mywriting の規範全体を適用する。

作業に応じて次のとおり読む。

- **新しく文章を書く**：formatting.md・composition.md・deslop.md を読む。
- **複数ファイルからなる文書群を書く・ファイル分割を再編する**：structure.md も読む。
- **既存の下書きをリライト・推敲する**：deslop.md を必ず読む。論証・構成に手を入れるなら composition.md も読む。
- **表記だけ整える**：formatting.md のみ読む。
