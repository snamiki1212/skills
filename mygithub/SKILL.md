# GitHub 操作の規範

GitHub の PR・Issue・レビューコメントを扱うときは、この skill に従う。

この skill は、GitHub 操作を安全に進め、相手が次に判断すべきことをすぐ分かる形で残すための規範である。

- **コードレビューへの返信**：`references/review-replies.md` を読む。
- **PR・Issue の作成、PR のマージと報告**：`references/creation-and-attribution.md` を読む。
- **AI が GitHub へコメント・レビュー・Issue・PR を投稿する操作**：`references/creation-and-attribution.md` を読む。

依頼が複数にまたがるときは、該当する reference をすべて読む。
